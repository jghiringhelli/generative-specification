## If you only have an hour

Read the [two-page introduction](/docs/gs-two-pager.html), then follow [your first hour](/START-HERE.html) on a project of your own. Everything else on the site is there to deepen that hour.

## How the lessons connect

The method is a loop. You write down what the system must be (a **spec**). A small map tells the assistant what to load for each task (the **sentinel**). The assistant derives the code. Something outside the model checks the result (a **gate**), and every miss leaves a permanent rule behind (the **ratchet**). The **seven properties** tell you how well a project does all of this, one letter each.

Every route above walks that loop. They differ only in where they start.
